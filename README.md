# Risk-Based-Portfolio-Allocation
This repository explores risk-based portfolio allocation strategies—specifically Equal Risk Contribution (ERC) and Hierarchical Risk Parity (HRP)—applied to the Euro Stoxx 50 universe. It evaluates these strategies using various covariance estimators, including sample covariance, constant-correlation shrinkage, and single-factor shrinkage. The HRP implementation includes correlation detoning (removing the first principal component) and tests multiple linkage methods and distance metrics to analyze cluster stability and weight sensitivities. The project concludes by backtesting both ERC and HRP portfolios, comparing their performance, drawdowns, and turnover against optimization-based approaches.

### Project context: 
Assignment for the Financial Engineering course @ Politecnico di Milano
